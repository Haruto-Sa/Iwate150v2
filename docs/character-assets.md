## プレビューの再生成

`public/assets/characters/previews/*.png` は同梱モデルをCharacter画面で描画したもの。風景写真や別のキャラクターで代替しない。モデル読込失敗時は再試行でき、別モデルに置換しない。

1. DB未接続のローカルサーバーを起動する（例: `bun run dev --port 3104`）。
2. `bun run scripts/capture_character_previews.ts http://127.0.0.1:3104` を実行する。
3. 5枚を目視し、モデル・色・全体の収まり・名前との一致を確認する。

スクリプトはlocalhostのみ、全体180秒、各操作30秒で制限。各対象の成功したモデルURLを照合し、正面へ戻し、操作パネルを隠してキャプチャする。モデル形状やテクスチャを変更した場合は再生成する。
