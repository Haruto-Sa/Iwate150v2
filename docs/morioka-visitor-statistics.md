# もりおか歴史文化館の入場者数

Issue #10の出典付き施設統計を追加する。検索対象の施設名・自治体名が完全一致した場合だけ表示し、盛岡市全体・盛岡城跡公園・隣の子ども科学館へ数値を流用しない。

## 原資料と確認

[盛岡市統計書（令和6年版）「市民の生活」PDF1ページ](https://www.city.morioka.iwate.jp/_res/projects/default_project/_page_/001/039/501/R6_shiminnoseikatsu.pdf#page=1)の最下段「入場者数」に、令和6年度・歴史文化館249,188人と記載されている。2026-11-28に公式PDFを取得し、画像で年度・施設名・単位を確認した。原資料の略称「歴史文化館」は、岩手県の[令和7年度社会教育基本調査](https://www.pref.iwate.jp/_res/projects/default_project/_page_/001/097/005/r7kihonchousa.pdf)の施設名「もりおか歴史文化館」・同数値でも照合した。

画面には2024年度・入場者数・249,188人と公式PDFへのリンクを表示する。観光客の実人数や市全体の観光客数とは読み替えない。既存の龍泉洞（2022年度・観光客入込数）とは年度・指標が異なるため、比較順位を追加しない。未掲載施設を0人とは扱わない。

## 関連ファイル

- src/lib/spotVisitorStatistics.ts: 出典付き施設統計
- src/lib/spotVisitorStatistics.test.ts: 施設・自治体照合と対象外への非流用
- e2e/spot-statistics.spec.ts: 検索結果の年度・指標・値・リンク

Supabaseテーブルやデータの変更はない。既存のスポット情報取得後に施設名と自治体名で照合する。実DBの接続・データ反映は別の検証であり、この変更のブラウザー検査はモックデータで行う。
