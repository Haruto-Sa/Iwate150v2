# 出典付き統計と編集おすすめ

Issue #10では、施設別の公表値と編集による紹介を区別する。公表値は年度・指標・単位・施設・出典を表示し、未掲載をゼロにしない。現在の龍泉洞と歴史文化館は年度と指標が異なるため、比較順位を付けない。

## 編集選定

本変更では地域と体験の幅を広げる観点で次の3施設を選んだ。来訪者数、口コミ数、認知度の調査による選定ではなく、「人が少ない」「人気が低い」とは判定していない。岩手県公式観光サイトの説明を2026-11-28に確認した。

| 施設 | 地域・選定理由 | 公式資料 |
| --- | --- | --- |
| 御所野遺跡 | 県北の縄文集落を公園と博物館でたどれる | [いわての旅](https://iwatetabi.jp/spots/5277/) |
| 鉄の歴史館 | 沿岸の製鉄の歴史を模型・映像で学べる | [いわての旅](https://iwatetabi.jp/spots/4872/) |
| 奥州宇宙遊学館 | 県南の天文観測の歴史と宇宙シアターに触れられる | [いわての旅](https://iwatetabi.jp/spots/5741/) |

カードには「編集おすすめ」と表示する。既存の施設説明が紹介内容を伝えるため、同じ説明を追加しない。検索・ホーム・お気に入りで同じ施設カードを表示する場合も同じ判定を用いる。表示順や検索条件は変更しない。

## 実装・検証

`src/lib/spotEditorialPicks.ts`は施設名と自治体名を完全一致で照合する。DBとモックで異なるIDには依存せず、別自治体や部分一致へおすすめを流用しない。統計の掲載有無からおすすめを推定しない。

関連ファイル: `src/components/ui/SpotCard.tsx`、`src/lib/spotEditorialPicks.test.ts`、`e2e/spot-statistics.spec.ts`。施設統計の原資料は`docs/morioka-visitor-statistics.md`に記録する。Supabaseテーブル・環境設定の変更はなく、実DBの確認とは分けて検証する。
